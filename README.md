# Roséa Boutique 🌹

Proyecto web desarrollado para la asignatura Desarrollo de Aplicaciones Web (ISW-306).

## Fase 3 - Backend, sesiones y acceso a datos

Roséa Boutique es una tienda virtual desarrollada con PHP, MySQL, HTML, CSS y JavaScript.

### Tecnologías utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP
- phpMyAdmin
- Git y GitHub

### Funcionalidades del backend

- Registro de usuarios.
- Inicio y cierre de sesión.
- Manejo de sesiones con PHP.
- Protección de páginas administrativas.
- Roles de cliente y administrador.
- Conexión a MySQL mediante PDO.
- Gestión de productos.
- Control de inventario y existencias.
- Creación y administración de pedidos.
- Gestión de estados de pedidos.
- Control de pagos.
- Carga y verificación de comprobantes.
- Seguimiento de envíos.
- Panel administrativo.

### Base de datos

Base de datos:

`rosea_boutique`

Tablas principales:

- usuarios
- productos
- pedidos
- detalle_pedido

Las tablas se encuentran relacionadas mediante claves primarias y foráneas.

### CRUD

El sistema permite realizar operaciones de:

- Create: agregar productos y registrar pedidos.
- Read: consultar productos, usuarios y pedidos.
- Update: editar productos y actualizar pedidos.
- Delete: eliminar productos desde el panel administrativo.

### Servidor local

El proyecto se ejecuta mediante XAMPP utilizando Apache y MySQL.

Ruta local del proyecto:

`C:\xampp\htdocs\rosea_boutique`
